Get Started

Running in 4 Simple Steps

Takes around 5 minutes, first time only. Once setup, it connects instantly whenever Studio is open.

1

Install the VoidScript Extension

Download the GitHub repository, then load voidscript-extension as an unpacked extension in Chrome / Edge (or via about:debugging on Firefox).

2

Enable Built-in MCP in Roblox Studio

Open any Roblox place → click Assistant → Manage MCP Servers → turn on Enable Studio as MCP Server.

3

Run the Local Bridge

Double-click start.bat in the repository folder. Keep the lightweight command window running in the background.

./start.bat
4

Start Building Your Game

Open any supported AI chat tab (like DeepSeek or Gemini), click Start session in the VoidScript bar, and describe what you want to make!

Frequently Asked Questions

Everything you need to know about VoidScript's security, MCP protocol, and AI support.

VoidScript runs as a lightweight browser extension that bridges your active AI chat browser session directly to your local computer's Roblox Studio MCP server. Because it uses the web chat interface you already have open (DeepSeek, Gemini, ChatGPT, etc.), you don't need to purchase or configure developer API keys.

Yes. VoidScript communicates exclusively on localhost (your own machine) between your browser and Roblox Studio. It never transmits your place data, scripts, or credentials to any external server. Because it is 100% open-source under GPL-3.0, any developer can inspect the entire codebase.

MCP (Model Context Protocol) is an open standard supported officially by Roblox Studio. When enabled under Studio's Assistant settings, it opens a local JSON-RPC server that allows authorized local tools to read scripts, write code, inspect hierarchy, and execute Luau cleanly and safely.

We recommend starting with DeepSeek (V3 / R1) or Google Gemini (1.5 Pro / Flash). Both are 100% free, require zero subscription, and have been hand-tuned in VoidScript for top-tier Luau scripting and Roblox game development.
