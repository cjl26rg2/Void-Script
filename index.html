What it does

Your AI, hands-on in Studio

VoidScript drives Roblox Studio through the official MCP server — no copy-pasting code, no API keys, no terminal.

📝

Reads & edits scripts

The AI opens your scripts, understands them, and makes precise multi-file edits directly in Studio.

⚡

Runs Luau live

It executes Luau in your place to build, test, and fix — then reads the console output to self-correct.

🌲

Inspects the game tree

Searches instances, reads properties, and navigates your hierarchy to work with real context.

🎨

Generates assets

Creates meshes, materials and models, and inserts from the Creator Store straight into your game.

🧠

Remembers your project

Persistent project memory is saved inside your place, so the AI keeps context across sessions.

Get started

Running in four steps

Around five minutes, first time only.

1

Install the extension

Download the repo, then load voidscript-extension unpacked in Chrome/Edge (or via about:debugging on Firefox).

2

Enable MCP in Roblox Studio

Open a place → Assistant → Manage MCP Servers → Enable Studio as MCP Server.

3

Run the bridge

Double-click start.bat (Windows) or MacOS_Start.command (macOS). Keep the window open.

4

Start building

Open a supported AI, click Start session in the VoidScript bar, and describe what you want to make.
