§ 05 / Setup Protocol

Installation in Four Brief Stages

Select your operating system below to reveal exact terminal and file execution commands.

🪟 Windows Edition

Runs via standard command script (start.bat).

🍎 macOS Edition

Runs via terminal shell script (MacOS_Start.command).

100% LOCAL PROCESSING: All communication happens on localhost:44100. No code leaves your computer.
01

Install the Browser Extension

Download the repository from GitHub and load voidscript-extension as an unpacked extension in Chrome, Edge, or Firefox (about:debugging).

git clone https://github.com/cjl26rg2/Void-Script.git
02

Enable Built-in MCP in Roblox Studio

In Roblox Studio, open any place file → click Assistant → Manage MCP Servers → turn on Enable Studio as MCP Server.

03

Run the Local Bridge Server

Double-click start.bat in your repository folder. Keep the lightweight terminal window running while building.

./start.bat
04

Start Building Your Game

Open any supported AI chat tab (like DeepSeek or Gemini), click Start session in the VoidScript bar, and describe what you want to create!

§ 06 / Inquiries & Record

Common Questions Answered

Everything you need to know about VoidScript's security, MCP protocol, and GNU GPL-3.0 licensing.

VoidScript uses a browser extension that connects the AI chat tab you already have open (such as DeepSeek, Gemini, or ChatGPT) directly to your local computer's Roblox Studio MCP server. Because it utilizes your active browser session, you do not need to purchase or configure developer API keys.

Yes. VoidScript communicates exclusively on localhost (your own computer) between your browser and Roblox Studio. It never transmits your place data, scripts, or credentials to any external cloud server. Because it is 100% open-source under GPL-3.0, any developer can inspect the entire codebase.

MCP (Model Context Protocol) is an open standard supported officially by Roblox Studio. When enabled under Studio's Assistant settings, it opens a local JSON-RPC server that allows authorized local tools to read scripts, write code, inspect hierarchy, and execute Luau cleanly and safely.

We recommend starting with DeepSeek (V3 / R1) or Google Gemini (1.5 Pro / Flash). Both are 100% free, require zero subscription, and have been hand-tuned in VoidScript for top-tier Luau scripting and Roblox game development.
