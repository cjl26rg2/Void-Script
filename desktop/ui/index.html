Workspace access off by default

Lets the built-in Chat read and write files and run commands — only inside one folder you choose (for example your Roblox project or Rojo folder). Paths outside it are blocked. How much it asks first depends on Access above the chat box: Ask approves every write and command, Sandbox only asks before deleting, and Full PC lifts the folder limit (deletes still ask).

Before you start

  • AI makes mistakes. It can break scripts or delete things in your place. Save and back up your work — VoidScript has Undo and place backups, but they are not a guarantee.
  • You are in control. The AI acts in your open Roblox Studio through the tools listed in this app. Stop it any time.
  • Workspace access is off by default. If you turn it on, the AI can read and change files and run commands inside the one folder you choose. Full PC access lifts that limit. Only use it with a model you trust, and read each approval before you allow it.
  • Chat sites and API providers see what you send them. Don't share secrets, passwords or personal data with the AI.
  • VoidScript is free, open-source software provided as is, without warranty, and is not affiliated with Roblox Corporation, NVIDIA or any AI provider.
