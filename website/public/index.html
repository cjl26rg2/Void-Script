How it works

Three steps, then just talk.

  1. 1

    Install VoidScript

    Download it, unzip it and open SpookyScript.exe (VoidScript.exe outside October). It sets itself up.

  2. 2

    Connect Studio

    In Roblox Studio, turn on Studio as MCP server in the Assistant settings. VoidScript finds it.

  3. 3

    Ask for anything

    Chat in the app with a free API key, or use the extension on any AI site. It builds straight into your place.

FAQ

Questions

Is it free?

Yes. VoidScript is free and open source (GPL-3.0). Many AI providers have free tiers, and the extension works with free AI websites.

Is it safe? My antivirus flagged it.

VoidScript is a new, unsigned app, so some antivirus tools warn about it the first time. All the code is public on GitHub, so you (or anyone) can read exactly what it does.

Does it work with my existing game?

Yes. It reads your scripts and instances first and makes small, surgical edits. Every change can be undone with Ctrl+Z in Studio, and you can back up your place from the app.

Is this an exploit?

No. It only works inside Roblox Studio, on places you own, through Roblox's own Studio MCP server. It never touches live games.

Is it made by Roblox?

No. VoidScript is an independent project and isn't affiliated with Roblox Corporation.
